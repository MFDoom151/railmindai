# Презентация (12 слайдов) — структура и тезисы

1. **Проблема.** Диспетчер вручную сводит десятки ограничений (пути, стрелки, платформы, ТО, приоритеты, локомотивы, бригады) → ошибки, простои, потеря пропускной способности.
2. **Решение.** «Цифровая станция»: модель инфраструктуры + ИИ-планирование + индекс эффективности + реальное время + автоматическое перепланирование при сбоях.
3. **Демо-картина.** Скриншот пульта: схема, диаграмма движения, индекс, конфликты, альтернативы.
4. **Архитектура.** `docs/architecture.svg`: источники → ingest → состояние → конфликты/индекс → планировщик → шина → WS/SSE → пульт; SQLite, конфиг, auth, метрики.
5. **Данные в реальном времени.** WS/SSE ≥ 2 Гц; валидация, дедупликация, переупорядочивание, сглаживание; reconnect + backoff; индикация «нет связи»; счётчики шума в UI.
6. **ИИ-планирование.** Постановка: пути/горловины/локомотивы/бригады/сортировочные пути/окна ТО/приоритеты; CP-SAT + эвристика; быстрый ответ за мс, оптимум за 1–2 с; устойчивость (hints, штраф за смену).
7. **Конфликты и узкие места.** 9 типов, решения «в один клик», диагностика причины.
8. **Индекс эффективности.** Формула, веса, пороги, категории, топ-5 вкладов — объяснимость.
9. **Нештатные ситуации.** Альтернативные планы: время расчёта, влияние на индекс, «без вмешательства» как база; нагрузочный сценарий ×10.
10. **Инженерия.** Модульность, конфигурация без перекомпиляции, роли и секреты через env, метрики, тесты (21), Docker Compose, OpenAPI.
11. **Результаты замеров.** Из `tools/load_test.py`: ≥ 2 кадра/с на клиента при 20 подписчиках, приём всплеска ×10 — единицы мс, обновление плана < 200 мс, финальные альтернативы 1–2 с.
12. **Дорожная карта.** Реальные данные (ЭЦ/АСУ), брокер сообщений, RL-подсказки, прогнозирование опозданий ML, многостанционная оптимизация, интеграция с 3D-двойником.
